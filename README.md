# PP Downloader

Сваля откъси от видеа (YouTube, bnt.bg и всичко, което поддържа yt-dlp) по таймкод, с handles, в H.264/AAC MP4.

## Преносима папка

```
PP_Downloader.exe
bin\yt-dlp.exe      — намира видео потоците
bin\ffmpeg.exe      — сваля само нужния участък и кодира в H.264
bin\ffprobe.exe
bin\deno.exe        — нужен на yt-dlp за YouTube
```

Цялата папка може да се копира на друг компютър с Windows 10/11, без инсталация.

## Работа

1. Поставяш линк, избираш **Начало** и **Край** (ЧЧ:ММ:СС). В полето „или 1:23:45“ може да се напише таймкод направо.
2. **➕ Добави линк** (под последния ред) добавя нов ред.
3. **⧉** дублира реда: същият линк, следващ откъс.
4. **⬇ Свали всички**.

Реже се от `начало − handles` до `край + handles` (по подразбиране ±5 сек). Името на файла съдържа въведените таймкодове:
`Заглавие [00-12-30_00-14-05].mp4`.

### Режими
- **Прецизно** (по подразбиране): рязане точно до кадър, прекодиране с libx264 `-preset slow -crf 16` (практически без видима загуба), AAC 320 kbps.
- **Бързо**: ако източникът вече е H.264, видеото се копира без загуба. Началото пада на най-близкия ключов кадър *преди* таймкода (няколко секунди повече handle). Иначе се прекодира.

Избира се най-високата резолюция и fps. При еднакви се предпочитат H.264 и AAC.

### Ако YouTube спре да работи
Натисни **Обнови yt-dlp**. YouTube често променя сайта си и yt-dlp се обновява почти всяка седмица.

## Компилиране

Rust (toolchain `stable-x86_64-pc-windows-gnu`) + MinGW (`dlltool` в PATH):

```
cargo build --release
cargo test --release -- --ignored --nocapture   # реален тест: сваляне от YouTube и bnt.bg
```
